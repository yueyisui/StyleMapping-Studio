# Privacy / 隐私说明

## 中文

StyleMapping Studio 按照本地优先方式工作：

- 用户选择的内容图、风格图和生成结果保留在用户设备上。
- 模型推理在 Windows 或移动设备本地完成。
- 应用不要求注册账号。
- 产品官网目前不包含用户追踪或分析脚本。
- 应用只会在本机启动本地网页服务，用于显示操作界面。

用户下载的安装包由 GitHub Releases 提供，因此下载过程适用 GitHub 的服务与隐私政策。

## English

StyleMapping Studio follows a local-first design:

- Content images, style references, and generated results remain on the user's device.
- Model inference runs locally on Windows or mobile devices.
- No account is required.
- The product website currently contains no user tracking or analytics scripts.
- The desktop application starts a local web service only to display its interface.

Release packages are downloaded through GitHub Releases and are therefore subject to GitHub's applicable service and privacy policies.
